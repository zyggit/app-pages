macOS menu bar utility

网络状态，一眼确认。

OhMyIp 在菜单栏展示公网 IP、国家与城市，并通过状态点帮助你确认当前 IP 是否符合预期。

无需 OhMyIp 账号 无广告 无跨 App 跟踪 macOS 13 或更高版本

功能介绍

专为菜单栏设计，把公网 IP、位置、网络延迟与预期状态集中在一个轻量窗口中。

菜单栏快速查看

启动后，OhMyIp 会常驻 Mac 屏幕右上角。菜单栏图标显示当前 IP 所在国家的旗帜，点击后即可查看并复制公网 IP。

预期 IP 状态提醒

绑定需要使用的公网 IP 后，旗帜右上角的绿点表示符合预期，红点表示 IP 已变化或不匹配。

城市信息与本地缓存

添加自己的 APILayer IPapi API Key 后可以查看城市信息。查询结果会按公网 IP 缓存在本机，同一个 IP 不会重复消耗接口额度。

自动刷新与网络感知

可在设置中选择自动刷新间隔。网络接口变化或网络恢复时，OhMyIp 也会及时重新检查公网 IP，并在刷新按钮上显示周期进度。

网络延迟检测

通过你指定的 HTTPS 基准地址测量往返延迟，结果直接显示在公网 IP 旁边。该数值用于了解连接响应速度，不代表下载速度。

本地 IP 历史

在设置的“IP 历史”中查看这台 Mac 使用过的公网 IP、国家、城市、首次发现时间、最近使用时间和出现次数。

登录时启动

可以让 OhMyIp 在登录 Mac 后自动运行。登录项权限始终由 macOS 管理，也可在“系统设置 → 通用 → 登录项”中随时关闭。

隐私友好的本地设置

OhMyIp 不需要账户，也不会进行跨 App 跟踪。预期 IP、城市缓存和历史记录保存在本机，API Key 安全存放在 macOS 钥匙串中。

常见问题

为什么在程序坞或“强制退出”窗口中找不到 OhMyIp？

OhMyIp 是菜单栏应用，默认不显示程序坞图标。请在屏幕右上角查找国旗图标；如果菜单栏空间不足，可暂时退出其他菜单栏应用或在“应用程序”文件夹中重新打开 OhMyIp。

城市信息为什么没有显示？

请确认已添加有效的 APILayer IPapi API Key、Mac 可以联网且免费套餐仍有请求额度。公网 IP 未变化时会直接使用本地缓存。

为什么状态点没有出现？

只有启用“预期 IP 监控”并保存一个有效 IP 后才会显示状态点。没有配置时，菜单栏只显示国家旗帜。

如何删除保存的数据？

可在设置中清除预期 IP、城市缓存和 API Key。卸载应用会删除沙盒内的本地设置；登录项也可在 macOS 系统设置中关闭。

应用需要登录账户吗？

不需要。OhMyIp 没有账号系统。可选的城市查询使用你自己的 APILayer 账户 API Key，该账户由 APILayer 独立提供和管理。
