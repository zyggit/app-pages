快速开始

查看公网 IP

启动后，OhMyIp 会出现在 Mac 屏幕右上角的菜单栏。点击国旗图标即可查看并复制当前公网 IP、国家和城市信息。

绑定预期 IP

打开“设置 → 通用设置”，填入预期 IP 并启用监控。绿点表示匹配，红点表示发生变化或不匹配。

显示城市

城市查询为可选功能。请在设置中添加自己的 APILayer IPapi API Key。OhMyIp 会按公网 IP 缓存城市结果，同一 IP 无需重复请求。

自动刷新与登录启动

你可以选择自动刷新间隔，并允许 OhMyIp 在登录 Mac 时启动。登录项权限可随时在 macOS“系统设置 → 通用 → 登录项”中管理。

常见问题

为什么在程序坞或“强制退出”窗口中找不到 OhMyIp？

OhMyIp 是菜单栏应用，默认不显示程序坞图标。请在屏幕右上角查找国旗图标；如果菜单栏空间不足，可暂时退出其他菜单栏应用或在“应用程序”文件夹中重新打开 OhMyIp。

城市信息为什么没有显示？

请确认已添加有效的 APILayer IPapi API Key、Mac 可以联网且免费套餐仍有请求额度。公网 IP 未变化时会直接使用本地缓存。

为什么状态点没有出现？

只有启用“预期 IP 监控”并保存一个有效 IP 后才会显示状态点。没有配置时，菜单栏只显示国家旗帜。

如何删除保存的数据？

可在设置中清除预期 IP、城市缓存和 API Key。卸载应用会删除沙盒内的本地设置；登录项也可在 macOS 系统设置中关闭。

应用需要登录账户吗？

不需要。OhMyIp 没有账号系统。可选的城市查询使用你自己的 APILayer 账户 API Key，该账户由 APILayer 独立提供和管理。
