OhMyIp 隐私政策

生效及最后更新日期：2026 年 9 月 9 日

OhMyIp 无需注册账号，不包含广告或跨 App 跟踪。应用设置、预期 IP、IP 历史、城市查询缓存及流量汇总均保存在你的 Mac 本地。

1. 适用范围

本隐私政策适用于 macOS 应用 OhMyIp。OhMyIp 是一款菜单栏网络工具，用于展示公网 IP、国家、可选的城市信息，以及判断当前 IP 是否符合用户设置的预期值。

2. 处理的数据

公网 IP 与国家

应用启动、手动刷新或按你设置的时间间隔自动刷新时，会访问 country.is 获取当前公网 IP 和国家代码。任何网络请求都会使服务提供方看到发起请求的公网 IP。OhMyIp 不运营自己的服务器，也不会在开发者服务器上保存这些请求。

可选的城市与地区查询

OhMyIp 会将当前公网 IP 发送给 IPWhois.io 免费接口，并将请求字段限制为 IP、国家、地区和城市。如果你主动添加 APILayer API Key，应用会优先将当前公网 IP 和该 Key 发送给 APILayer IPapi 的 HTTPS 接口；未配置 Key、套餐不支持 HTTPS 或 APILayer 请求失败时才使用 IPWhois.io。API Key 与 APILayer 账户由你自行管理，并受 APILayer 的条款及隐私政策约束。

固定地址延迟检测

刷新时，OhMyIp 会向固定的 Google 官网 HTTPS 地址发送不含用户内容的请求以测量连接响应时间。Google 会像处理普通网络请求一样看到发起请求的公网 IP。该检测不用于测量下载速度或检查浏览内容。

本地网络流量

OhMyIp 读取 macOS 提供的物理网络接口收发字节计数，用于计算实时速率和本机累计流量。这些统计数据保存在本地；应用不会读取或保存数据包内容、访问域名或其他 App 身份，也不会将流量统计发送给开发者或第三方。

应用设置与诊断信息

预期 IP、是否启用监控、通知偏好、自动刷新间隔、IP 历史、城市查询缓存及流量汇总保存在应用沙盒的本地偏好设置中。APILayer API Key 保存在 macOS 钥匙串中。OhMyIp 不接入第三方广告、分析或崩溃报告 SDK。

3. 处理目的与数据关联

公网 IP 与粗略位置仅用于提供应用功能：展示网络出口信息、判断预期 IP 是否匹配，以及显示用户主动请求的城市信息。这些数据不用于广告，不用于跨 App 或网站跟踪。使用 APILayer 时，服务方可能依据你的 API Key 将请求与 APILayer 账户关联。

4. 缓存与请求频率

为减少外部请求，OhMyIp 会按公网 IP 缓存成功的城市查询结果。公网 IP 未变化时，应用优先读取本地缓存，而不会重复请求城市接口。刷新公网 IP 和国家信息仍会访问 country.is；延迟检测仍会访问固定的 Google 官网地址。

5. 第三方服务

  • country.is：提供公网 IP 与国家查询。请参阅 country.is 网站发布的隐私说明。
  • APILayer IPapi：在你主动配置 API Key 后提供城市与地区查询。请参阅 APILayer 隐私政策与服务条款。
  • IPWhois.io：在未配置 APILayer Key 或 APILayer 请求失败时提供城市与地区查询。请参阅 IPWhois.io 隐私政策与服务条款。
  • Google：作为固定的 HTTPS 延迟检测地址。请参阅 Google 隐私政策。
  • Apple ServiceManagement：在你启用登录启动时，由 macOS 管理 OhMyIp 登录项状态。

我们要求处理 OhMyIp 功能数据的第三方依据其公开政策和适用法律提供与本政策一致或同等水平的保护。若第三方服务的实际做法发生重大变化，我们会评估影响、更新本政策，并在必要时停止相关集成。

6. 删除与控制

  • 在 OhMyIp 设置中清除预期 IP 配置、城市缓存与 APILayer API Key。
  • 在 macOS“系统设置 → 通用 → 登录项”中关闭登录启动。
  • 卸载 OhMyIp 可删除应用沙盒内的本地数据；你也可以先在应用内删除钥匙串中的 API Key。

7. 儿童隐私

OhMyIp 不面向 13 岁以下儿童，不会故意收集儿童个人信息。

8. 政策更新与联系我们

如本政策发生重要变化，我们会更新本页面及顶部日期。如有隐私问题，请发送邮件至 heartwave_app@163.com。请勿通过邮件发送 API Key。

OhMyIp Privacy Policy

Effective and last updated: September 9, 2026

OhMyIp requires no OhMyIp account and contains no advertising or cross-app tracking. App preferences, the expected IP, IP history, city lookup results, and traffic totals are stored locally on your Mac.

1. Scope

This policy applies to the OhMyIp macOS application. OhMyIp is a menu bar utility that displays a public IP address, country, optional city information, and whether the current IP matches a value configured by the user.

2. Data processed

Public IP address and country

When the app starts, refreshes automatically, or is refreshed manually, it contacts country.is to retrieve the current public IP address and country code. Any network request makes the originating public IP visible to the service provider. OhMyIp operates no developer server and does not retain these requests on a developer server.

Optional city and region lookup

OhMyIp sends the current public IP to the IPWhois.io free endpoint with a field list limited to IP, country, region, and city. If you add an APILayer API key, the app first sends the current public IP and that key to the APILayer IPapi HTTPS endpoint. It uses IPWhois.io when no key is configured, the plan does not support HTTPS, or the APILayer request otherwise fails. You manage the API key and APILayer account under APILayer's terms and privacy policy.

Fixed-endpoint latency test

During refresh, OhMyIp sends a request containing no user content to the fixed Google website HTTPS endpoint to measure response time. Google sees the originating public IP as it would for an ordinary network request. This does not measure download speed or inspect browsing content.

Local network traffic

OhMyIp reads macOS network-interface byte counters to calculate live rates and local traffic totals. These statistics remain local. The app does not inspect or store packet contents, visited domains, or other app identities, and does not transmit traffic statistics to the developer or third parties.

App preferences

The expected IP, monitoring and notification choices, refresh interval, IP history, city lookup cache, and traffic totals are stored in local preferences. The APILayer API key is stored in the macOS Keychain. OhMyIp includes no third-party advertising, analytics, or crash-reporting SDK.

3. Purpose, linking, and tracking

Public IP and coarse location information are used only to provide app functionality. They are not used for advertising or tracking across apps or websites. When APILayer is used, that provider may associate requests with your APILayer account through your API key.

4. Local caching

To reduce external requests, OhMyIp caches a successful city response by public IP. If the public IP has not changed, the app uses the local cache instead of repeating the city request. Refreshing public IP and country information still contacts country.is, and the latency test still contacts the fixed Google website endpoint.

5. Your controls

  • Clear expected-IP settings, city cache, and the APILayer API key inside OhMyIp settings.
  • Disable launch at login in macOS System Settings → General → Login Items.
  • Uninstall OhMyIp to remove sandboxed app data. You may first remove the API key inside the app.

6. Third-party protection

We require third parties that process data for OhMyIp functionality to provide protection consistent with or equivalent to this policy under their published policies and applicable law. If a provider's practices materially change, we will assess the impact, update this policy, and discontinue the integration when necessary. See the published policies of country.is, APILayer, IPWhois.io, and Google.

7. Contact

For privacy questions, email heartwave_app@163.com. Do not send API keys by email.
