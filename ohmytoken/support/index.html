快速开始

iPhone / iOS

  1. 打开 OhMyToken，选择需要连接的服务。
  2. 按照连接页说明完成授权或粘贴所需凭据。
  3. 连接成功后返回总览，手动刷新确认额度。
  4. 添加主屏幕小组件以查看最近快照。

Mac / macOS

  1. 首次打开时阅读本机访问说明。
  2. 选择“允许只读访问”后，应用才会检查本机 Agent 登录。
  3. 在设置中选择 Provider 的自动、显示或关闭状态。
  4. 需要时开启本机 Token 消耗扫描。

常见问题

显示“未连接”怎么办？

确认对应官方客户端或 CLI 已登录，并重新打开连接页。若使用手动连接，请确认凭据完整、未过期且属于对应服务。

为什么刷新失败或显示数据过期？

先确认网络及对应服务可用，再执行手动刷新。服务商接口、账号计划或登录状态变化也可能导致暂时无法取得额度；旧快照会标记为过期而不会伪装成实时数据。

为什么授权后仍检测不到本机 Agent？

确认客户端使用默认数据目录并已完成登录。沙盒版本只能读取应用声明的只读目录；自定义安装路径可能无法自动识别，可尝试连接页提供的手动方式。

如何撤销本机读取授权？

打开“设置 → 本机读取”，关闭“允许读取本机 Agent 登录与会话”。自动刷新和本机会话扫描会立即停止，已保存的额度快照仍可查看。

为什么没有本机 Token 消耗数据？

本机消耗目前以可识别的 Codex、Grok 会话记录为来源。请确认已授权本机读取、开启消耗扫描，并且所选时间范围内存在会话记录。

小组件没有更新怎么办？

先打开主应用并完成一次刷新。小组件读取主应用写入 App Group 的最近快照，系统可能根据电量和使用情况调整刷新时间。

如何断开账号并删除数据？

在账号详情中选择断开账号。OhMyToken 会删除自己保存的该账号凭据、快照和趋势记录，但不会删除或修改第三方 Agent 客户端自己的文件。

支持哪些系统？

当前版本支持 iOS 17 或更高版本，以及 macOS 14 或更高版本。Mac 版提供菜单栏、本机 Agent 检测和本机会话汇总。
